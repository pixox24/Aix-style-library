# 宿主绘图工具交接记录

本文件只记录**已经实际验证**的生成工具。字段以可获得的真实契约为准，禁止从模型家族名字推断参数。

## 当前状态（预览版 0.1.0）

| 项 | 状态 |
|---|---|
| 已验证的宿主 | 无 |
| 已验证的生成工具 | 无 |
| 已验证的参考图输入 | 无 |
| 可用能力 | 仅 `generic-text-v1` 提示词契约 |

本环境没有完成真实图像生成工具的验证。因此：

- 用户要求出图且宿主没有可用工具时，交付 `prepare` 的提示词结果并附 `GENERATION_UNAVAILABLE`，不声称已生成。
- 不得把未验证的工具写进本文件，也不得把 v1.0 的工具验收项标为通过。
- 本预览版不携带任何 API 密钥，也不自行搭建生成服务。

## 新增一个已验证工具时必须记录

| 必须记录 | 内容 |
|---|---|
| 工具身份 | 宿主、实际工具名称、模型/版本或可获得的标识 |
| 核对日期 | 参数契约的实际核对时间 |
| Prompt 入口 | 文本字段名称、长度及语言限制 |
| 画幅 | 支持的比例或尺寸值；从请求到工具值的映射 |
| 负向词 | 是否有独立字段；没有就保留自然语言约束 |
| 参考图 | 是否支持、如何传入；默认不使用缩略图 |
| 结果判断 | 能证明生成完成的状态、图片文件/返回资源形式 |
| 失败 | 未登录、配额、网络、参数问题如何反馈 |
| 测试证据 | 真实调用记录所在路径 |

## 交接流程

1. 确认用户请求包含生成意图，且 `prepare` 成功。
2. 使用已发现工具的真实契约，映射提示词和支持的比例/尺寸。
3. 用户未授权改变的文字、主体、比例不能静默降级。
4. 工具无法精确提供比例时，可记录 `RATIO_APPROXIMATED`；否则明确说明并征求选择，不偷偷改成横图。
5. 调用已有生成工具，遵循其权限和费用要求。
6. 只有实际返回可访问图片或明确成功资源才记录 `generated`。任务刚提交/排队不算完成。
7. 对最终图核对主体、画幅、明显文字错误与风格。失败如实描述，不设无限重试。

## 生成记录

宿主内本次任务至少保留：风格 provenance、最终提示词、请求比例、实际工具身份、实际参数、实际图片引用及生成状态。工具暴露 seed 才记录，未暴露不编造。默认不主动永久写盘或上传。
