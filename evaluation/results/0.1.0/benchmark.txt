Aix 图片风格库 本地性能基准（预览版 0.1.0）
================================================

测量方法（PRD 第 14.3 节）
- 预热 1 次，之后每个操作运行 30～40 次，取 p50 / p95。
- 包含 CLI 进程启动；排除 Agent 推理、绘图与冷盘首次读取。
- 命令：python <skill-root>/scripts/aix.py get --id 0001
        python <skill-root>/scripts/aix.py search --input <request.json>

环境
- Python：3.14.0
- 平台：Windows-10-10.0.19045-SP0
- CPU 逻辑核：16
- 空 Python 解释器启动基线：p50 ≈ 182 ms，p95 ≈ 200 ms

结果
- 真实库（3 个风格，40 次）
  get     p50 = 259 ms   p95 = 279 ms   目标 p95 ≤ 300 ms   PASS
  search  p50 = 262 ms   p95 = 269 ms   目标 p95 ≤ 800 ms   PASS

- 合成库（1000 个风格，20 次）
  get     p50 = 257 ms   p95 = 258 ms   目标 p95 ≤ 300 ms   PASS
  search  p50 = 281 ms   p95 = 298 ms   目标 p95 ≤ 800 ms   PASS

说明
- 该主机空解释器启动约 200 ms，占绝对延迟的主要部分；脚本自身逻辑在 get 上仅增加约 10 ms。
- 1,000 个风格的索引在内存中读入并按需回读候选，未返回整份索引。
- 运行命令无第三方依赖、无网络请求、无风格库写入。
