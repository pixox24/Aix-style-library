# Aix 图片风格库 验收报告（预览版 0.1.0）

- 日期：2026-09-18
- 库版本：0.1.0（schema 1.0 / api 1.0）
- 范围：工程闭环验收（get/search/prepare/validate/build-index/索引/发布/回滚/测试）
- 结论：**工程验收通过；未达到 PRD 定义的正式 v1.0 优秀级（9.0），按 §13.3 交付为预览版。**

## 1. 一句话结论

工程部分（调用正确性、数据与维护可靠性、效率、说明）已达到 9 分标准；但 PRD 的 9.0 硬门槛要求 20 个真实 active 风格、120 张真实视觉测试与一个已验证生成工具，本环境无真实素材与图像工具，该部分如实未达标。因此**不声明达到正式 v1.0 的 9 分**。

## 5. 与 9.0 的差距清单

要真正达到 PRD 的 9.0 优秀级，还需：

1. 内容：补齐 20 个真实风格，覆盖 ≥3 个一级分类，去掉预览占位。
2. 视觉：每风格人物/物体/场景各 2 张，共 ≥120 张真实结果；一致性 ≥4 比例 ≥90%，内容保留 ≥4 比例 ≥95%；至少一名非作者复核（或盲复评并记录限制）。
3. 工具：在目标宿主实际验证一个图像生成工具，填写 `references/host-tools.md`，完成 §16.5 附加验收。
4. 宿主：在真实 Codex 环境安装、发现、显式调用并做冒烟回归。
5. 行为记录：完成 32 例 × 3 次独立对话，共 96 条记录（`evaluation/results/<version>/`）。
6. 可移植：在 Windows 与一个 POSIX 系统上通过路径与编码测试。

## 6. 本轮已完成的验证

- 确定性测试：53 项，全部通过（`python -m unittest discover -s tests`）。
- 数据校验：`validate --scope all` 与 `validate --scope release --evidence-root evaluation` 均 OK。
- 端到端：get（含全角/五位数/草稿/弃用/版本不可用/路径逃逸/坏图）、search（命中/空结果/类别过滤/索引陈旧）、prepare（强度/排除/约分/文字保留/不适配）全部验证。
- 索引：同输入构建字节一致；构建失败保留旧索引；候选回读校验。
- 发布与回滚：构建不可覆盖发布包 `releases/aix-style-library-0.1.0.zip`，解压后 get/search/prepare/validate 冒烟通过，`source_digest` 与源一致。
- 安全边界：数据内容不被执行（A32）；junction 逃逸被拒绝；stdout 仅一个 JSON，stderr 无堆栈。
- 前向测试：4 个独立上下文，31/32 用例行为正确；据此修正 A19 指代规则。

## 7. 遗留风险

- 缩略图为程序化示意，可能让用户误判真实风格观感；预览版已限制为内部/演示用途。
- 未验证宿主与生成工具，真实出图交接仍属未验证能力。
- POSIX 路径与编码未实测。
