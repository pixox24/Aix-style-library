# 0.1.1 可靠性修复验收

日期：2026-09-19。范围：发布校验、索引一致性、路径边界、错误协议和组包。结论：本轮已复现缺陷已修复，合法预览包通过校验与解包运行；仍然是预览版，不代表正式视觉、工具和 Agent 行为验收完成。

## 改动

- release 真正使用 JSON Schema 与 Pillow；拒绝不可解码图片、错误格式/尺寸/体积、重复 ID/路径/像素、缺题材、低分及不一致证据。依赖缺失明确失败，不自动安装。
- 0.x.y 明确返回 preview / PREVIEW_ONLY；正式版本要求 ≥20 个 active 风格、≥3 类、真实生成记录声明、图片摘要以及与发布内容绑定的正式验收记录。
- validate 比较完整索引与源数据；search 检查结构、ID 集合和记录摘要，并回读核对选中候选的完整字段。get 仍不依赖索引。
- 最终 style.json、thumbnail.webp、library.json、索引及证据路径均检查真实边界。合法库内链接可用，库外链接被拒绝。
- 坏元数据、请求和未知命令返回单一 JSON 错误；补齐必要字段检查、响应分支 Schema、有效日期、重复参数、限量读取及 UTF-8 标准输出。
- 打包使用资源清单和临时 staging，排除 draft、临时请求与额外文件，保留有效弃用记录；重建索引、执行 release 校验和 ZIP 解包冒烟后，以不可覆盖方式发布。包名版本必须与内部一致，失败不留下新发布 ZIP。
- 修复 POSIX 测试直接调用 Windows cmd 的问题；加入 macOS/Linux/Windows × Python 3.11/3.14 CI 配置。

## 明确限制

- Windows/Linux CI 已配置但尚未在本次本机执行，不能声称跨平台全部实测通过。
- 自动校验能检查结构、资源、摘要及门槛声明，不能证明人为分数诚实、授权有效或声明的模型调用真实；正式发布仍需实际评审和可核对的原始记录。正式校验的通过分支使用标明 SYNTHETIC TEST ONLY 的临时夹具测试，没有把夹具加入正式素材或作为真实验收证据。
- 搜索相关性、提示词题材污染、真实生成工具、120 张视觉测试和 96 次 Agent 行为执行属于后续任务，本轮没有宣称完成。
- 本轮沿用未改动风格的 0.1.0 示意证据；库版本提升为 0.1.1，风格版本及内容摘要保持原值。
